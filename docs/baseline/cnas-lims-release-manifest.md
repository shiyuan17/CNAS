# CNAS LIMS 发布需求清单

> 清单编号：CNAS-LIMS-REL-001  
> 版本：0.2  
> 对应开发基线：BL-DEV-1.0（准备版，未批准）  
> 集合来源：`cnas-lims-requirement-catalog.md` 版本 0.9

## 1. 处置规则

- P0：全部纳入阶段 1 准备范围，但在 `BL-BIZ-1.0` 未批准前状态均为阻塞。
- P1：不纳入 `BL-DEV-1.0` 首期系统功能，逐条安排阶段 2 或阶段 3。
- P2：安排阶段 4，必须另行完成价值、安全和范围评审。
- `NFR-MAINT-001` 的系统化能力虽在阶段 2，但阶段 1 必须使用受控文档完成发布追踪，不允许无发布记录。
- 每行依赖按源需求中的全部 `TBD-*` 展开，斜杠缩写不得丢失后续编号。
- 每行 `DRS模块` 必须引用开发就绪规格中已定义的模块。
- 本清单不改变需求优先级，不代表已获得业务、开发或发布批准。
