# CNAS LIMS E1 业务证据接收区

> 状态：等待需求方提供受控资料。本目录当前不包含任何 E1 业务证据。

## 用途

本目录用于接收试点实验室已经批准并处于有效状态的质量体系文件、表单、案例、组织授权、接口和运维资料。只有完成来源、版本、有效性、批准状态和 SHA-256 核验的文件，才能在正式业务基线中作为 E1 证据引用。

通用产品需求、CNAS/标准主题、行业资料、页面原型和分析推导不得放入本目录冒充 E1 证据。

## 接收规则

1. 原始文件只接收和登记，不修改正文、元数据或签章。
2. 文件名建议使用 `证据编号__原文件名__版本__生效日期.扩展名`；原文件名存在受控要求时保持原名并在台账中登记证据编号。
3. 每份文件进入 [证据接收台账](./evidence-intake-register.md) 后才可被需求引用。
4. 失效、作废或被替代文件不得删除，必须登记替代关系并停止用于新需求确认。
5. 含客户、人员、商业秘密或检测/校准数据的文件必须先脱敏或按批准的访问范围保存。
6. 哈希只能证明接收内容未变化，不能替代批准人、有效期和适用性核验。

## 禁止事项

- 不得创建虚构的制度、表单、案例、批准人、签名或证据编号。
- 不得以 CNAS 官方文件直接替代实验室实际制度。
- 不得以候选 SRS、原型或开发实现证明业务已经批准。
- 不得在证据缺失时关闭 `TBD-*` 或将需求状态改为“已批准”。
