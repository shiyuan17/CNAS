# CNAS LIMS 详细需求目录

> 文档编号：CNAS-LIMS-FR-001  
> 版本：0.9  
> 状态：候选需求；所有 P0 标准驱动需求仍需 E1 业务证据确认

## 1. 编写规则

每一行是一条可独立评审和验收的需求。字段映射如下：

- “角色/前置”对应使用角色和前置条件。
- “主流程/输出”对应主要处理、输入和输出。
- “异常/状态/规则”对应异常流程、状态变化和业务规则。
- “权限/审计/验收”对应权限要求、审计要求和原子验收标准。
- 来源中的 `CL01 x.x` 是标准主题映射，不代替合法标准文本；业务实现均需按证据台账确认。

优先级：P0 为认可合规或核心业务必需，P1 为重要管理能力，P2 为效率能力，P3 为后续扩展。

## 19. 需求目录批准规则

1. 当前所有需求状态为“候选”。
2. P0 需求只有在关联 E1 证据或书面业务决策后，才能改为“业务已确认”。
3. P0 不允许以 `[推测]` 形式进入批准版；`[最佳实践建议]` 必须经价值和风险评审后选择优先级。
4. 任何需求修改必须同步更新追踪矩阵、验收场景和受影响流程/状态。
5. 正式批准由实验室负责人、质量负责人、技术负责人和项目负责人联合签署。
