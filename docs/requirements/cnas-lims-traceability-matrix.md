## 1. 追踪规则

正向链：`标准/制度/决策 → 业务要求 → FR/NFR/INT/RPT → 控制措施 → 保留记录 → 验收场景`。

反向链：每个验收场景必须回溯需求，每个 P0 需求必须至少出现在一条矩阵记录中。当前缺少 E1 制度证据，矩阵“业务证据状态”均保持阻塞或部分满足。

正式业务基线批准前，129 条 P0 还必须逐条关联 [E1 证据接收台账](../evidence/e1/evidence-intake-register.md) 中的具体证据位置或 [TBD 决策工作簿](../baseline/cnas-lims-tbd-decision-workbook.md) 中已签署的决定。开发阶段处置见 [发布需求清单](../baseline/cnas-lims-release-manifest.md)，不得用发布阶段决定替代业务证据。

## 5. 当前覆盖结论

- 候选 P0 需求均已分组映射到来源、控制、记录和验收场景。
- “追踪存在”不等同于“业务已确认”；当前所有分组仍受一个或多个 P0 `TBD` 阻塞。
- 业务方提供 E1 证据后，应逐条拆开范围表达 `FR-X-001~005`，记录准确制度章节、表单编号和案例编号。
