# CNAS-DESIGN-001 CNAS LIMS 全模块页面设计

- 工作流档位：完整
- 当前阶段：执行
- 当前状态：验证失败
- 处理结果：开放

## 目标

使用 `@pen.dev/cli@0.3.0` 与 web-ele 设计基线，交付四组可编辑 CNAS LIMS 页面设计、同名 PNG 预览和页面映射，并完成独立测试与红队审查。

## 验收标准

| AC-ID | 标准 |
| --- | --- |
| AC-01 | 四份 `.pen` 均有同目录同 basename 的 `.png`，可由 Pencil CLI 重新打开。 |
| AC-02 | 页面总数为 60，其中桌面 54、移动 6；四组数量依次为 9、20、19、12。 |
| AC-03 | 桌面画板为 `1440x900`，移动画板为 `390x844`。 |
| AC-04 | 每份设计包含统一变量与 13 个可复用组件，页面映射覆盖一级模块、12 条核心流程和主要角色。 |
| AC-05 | `snapshot_layout({ problemsOnly: true })` 无未解释的重叠、裁切或越界问题。 |
| AC-06 | 页面包含异常、预警、阻断、审批、审计以及移动状态，且使用虚构演示数据。 |
| AC-07 | 项目治理校验通过，Tester 与 Reviewer 对冻结变更集给出合格收据。 |

## 验证计划

- `node scripts/generate-cnas-pencil-designs.mjs --check-generated`
- `node scripts/generate-cnas-pencil-designs.mjs --validate-existing`
- 人工抽查四张联系表 PNG 及登录、工作台、样品、原始记录、报告签发、设备、CAPA、内审和认可整改页面。
- `node .agents/cognis/governance/validate.mjs`

## 下一步动作

等待独立 Tester 与 Reviewer 对冻结变更集完成并行只读核验。
