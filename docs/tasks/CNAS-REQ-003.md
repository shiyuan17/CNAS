## 目标

在不伪造 E1 业务证据、业务决策或四方签署的前提下，建立可执行的正式业务基线准备包和开发基线准入包：提供证据接收、25 项 TBD 决策、业务批准、首期发布、开发就绪规格和变更控制所需的完整模板与门禁，并保持候选 SRS 在外部证据齐备前不可批准。

| AC-ID | 标准 |
| --- | --- |
| AC-01 | 建立 E1 证据接收目录和统一清单，覆盖六类最低证据包及版本、批准、有效期、哈希、密级、适用域和替代关系。 |
| AC-02 | 25 项 TBD 全部进入八组可签署决策工作坊，每项包含方案、决定、理由、证据、影响需求、责任人、批准人、生效版本和风险。 |

- 校验新增 Markdown 表格、代码围栏、相对链接和基线状态声明。
- 对比详细需求目录与发布清单，验证 161 条需求集合完全一致，优先级计数为 P0=129、P1=31、P2=1。
